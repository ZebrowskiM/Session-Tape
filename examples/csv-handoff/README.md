Fictional contributor sample for onboarding and demos. All names, order IDs and
timestamps are invented.

Open the [sample report](report.md). From that file alone, identify the decision
to keep both orders and the next-day correction (and which earlier event it
references).

flow. It is not a screenshot of an implemented Session Tape feature.
